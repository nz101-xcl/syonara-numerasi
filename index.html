MODUL KONSEP & VISUALISASI

Barisan dan Deret Aritmetika

Pelajari 6 konsep fundamental beserta contoh kasus kontekstual, laboratorium grafik dinamis, dan tanya jawab langsung bersama ZETA AI.

KONSEP 01

Barisan Aritmetika (Un)

Susunan bilangan yang memiliki selisih atau beda tetap (b) antarsuku yang berurutan. Digunakan untuk mencari nilai pada satu posisi urutan tertentu.

Un = a + (n − 1)b
a = Suku pertama (U1) | b = U2 − U1 | n = Urutan suku
KONSEP 02

Deret Aritmetika (Sn)

Akumulasi penjumlahan dari suku pertama hingga suku ke-n. Digunakan untuk menghitung total tabungan, total hasil panen, atau kapasitas gedung.

Sn = n/2 (2a + (n − 1)b)
Jika Un diketahui: Sn = n/2 (a + Un)
KONSEP 03

Suku Tengah (Ut)

Pada barisan aritmetika dengan banyak suku (n) ganjil, nilai suku tepat di posisi tengah merupakan rata-rata dari suku pertama dan suku terakhir.

Ut = a + Un/2
Indeks posisi tengah: t = n + 1/2
KONSEP 04

Sisipan Barisan (b')

Jika di antara setiap dua suku berurutan disisipkan sebanyak k bilangan baru hingga membentuk barisan aritmetika baru, maka beda barunya adalah:

b' = b/k + 1
b = Beda awal | k = Banyak bilangan sisipan
KONSEP 05

Hubungan Un dan Sn

Nilai suku ke-n tunggal dapat diperoleh dari selisih jumlah deret hingga suku ke-n dengan jumlah deret hingga suku sebelumnya.

Un = Sn − Sn−1
Contoh: Besar tabungan khusus bulan ke-5 adalah U5 = S5 − S4.
KONSEP 06

Mencari Beda dari Dua Suku Jauh

Apabila suku pertama belum diketahui namun diketahui nilai suku ke-p dan suku ke-q, maka beda (b) ditentukan dengan:

b = Up − Uq/p − q
Contoh: Jika U7 = 32 dan U3 = 16, maka b = (32 − 16) / (7 − 3) = 4.

Analisis Perbandingan Kontekstual: Kapan Memakai Un, Sn, dan Pola Negatif?

1. Nilai pada Urutan Tertentu (Un)

Baris pertama gedung memiliki 20 kursi, baris kedua 24 kursi, dan baris ketiga 28 kursi. Berapa kursi pada baris ke-15?

Data: a = 20, b = 4, n = 15.
U15 = 20 + (14 × 4) = 76 kursi.

2. Akumulasi Total Keseluruhan (Sn)

Dengan kondisi gedung yang sama, berapa total kapasitas seluruh kursi di dalam gedung jika terdapat 15 baris?

Data: a = 20, U15 = 76, n = 15.
S15 = (15 / 2) × (20 + 76) = 720 kursi.

3. Pola Penyusutan / Menurun (b < 0)

Suhu ruang pendingin awalnya 18°C, lalu turun 4°C setiap jam. Berapa suhu ruang pada jam ke-7?

Data: a = 18°C, b = −4°C, n = 7.
U7 = 18°C + (6 × (−4°C)) = −6°C.
